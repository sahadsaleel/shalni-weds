# Shalu & Vaisakh — Premium Traditional Kerala Wedding Invitation

A luxurious, interactive digital wedding invitation designed for **Shalu & Vaisakh (Salini & Vaisakh)**. Built using modern web tech and styled with traditional Kerala aesthetics to provide a premium, heart-warming, and responsive invitation experience.

---

## 🎨 Design System & Aesthetics

Inspired by the cultural heritage of Kerala, the website is adorned with traditional elements and luxurious colors:
*   **Kasavu & Gold Accent (`#d4af37` / `#996515`)**: Emulating the classic golden borders of the Kerala Kasavu saree.
*   **Emerald Dark (`#0f3c24`)**: A deep, royal green representing the lush greenery and traditional background.
*   **Warm Ivory Background (`#faf8f5`)**: A soft, comforting, premium off-white canvas.
*   **Jasmine Garland Details**: Handcrafted floating jasmine flower icons (`jasmine-flower`) representing auspiciousness and traditional styling.
*   **Custom SV Monogram Favicon**: A customized emerald and gold initial crest matching the overall design language.

---

## ✨ Features

1.  **Luxury Hero Banner**: Dynamic greeting featuring custom typography and floating accents welcoming guests.
2.  **Auspicious Countdown**: A high-end real-time wedding countdown ticking down the days, hours, minutes, and seconds until the auspicious Muhurtham.
3.  **Groom & Bride Portraits**: A dedicated section displaying custom portrait cards of the couple within gold-bordered jasmine frames.
4.  **Wedding Details & Calendar Invite**: Easy-to-read wedding schedule (Muhurtham, Venue, Feast) with a built-in interactive calendar file (`.ics`) generator for guests to save the date directly to Google Calendar, Apple Calendar, or Outlook.
5.  **Clean Wedding Gallery**: A sleek, responsive masonry grid displaying high-resolution photographs of the couple's moments.
    *   *Clean Grid Layout*: Focused on the image content with subtle interactive hover scaling.
    *   *Framed Lightbox Modal*: Clicking any image opens a gorgeous full-screen framed lightbox, completely clean and free of text overlays.

## 🛠️ Technology Stack

*   **Framework**: [React 19](https://react.dev/)
*   **Build Tool**: [Vite 8](https://vite.dev/)
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/) for fluid, performance-optimized micro-interactions
*   **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone or download the repository to your local drive.
2. Open your terminal in the project directory and install the dependencies:
   ```bash
   npm install
   ```

### Development
Launch the local dev server with Hot Module Replacement (HMR):
```bash
npm run dev
```

### Production Build
Bundle and compile highly-optimized production assets (located in the `dist/` directory):
```bash
npm run build
```

### Preview Production
Locally preview your production build:
```bash
npm run preview
```
